# Stage 3 策略研究技术规范

## 1. 目标与交付等级

Stage 3 在 Stage 1/2 正式产物上研究股票资格、信号、目标组合、订单执行、账户和评价。

必须区分：

- **R1 研究近似回测**：日频价格代理、复权单位近似账和假设费用，可用于工程与因果研究。
- **R2 真实现金—股数回测**：需要另行验收公司行动、单位、整手、结算、公告可见时间和退市映射。
- **实盘**：不在当前能力范围内。

R1 通过不等于 R2、真实可成交收益或实盘就绪。当前机器权限以 `configs/strategy_research.yaml` 为准。

## 2. 输入、权限与时间范围

- 原始 `data/` 只读；策略模块不能直连原始表或修改 Stage 1/2 正式产物。
- 只消费获准的物理样本内快照或有界读取证明，并绑定输入、配置和代码身份。
- 默认数据上界为 2024-12-31；2025-01-01 起锁定，不能通过全期扫描、日历或标签绕权限。
- 预热：2018-06-01 至 2019-06-30。
- 设计 D：2019-07-01 至 2021-12-31。
- 内部验证 V：2022-01-01 至 2023-12-31。
- 样本内确认 C：2024 年。D/V/C 都是已见样本内分工，不称盲测。
- 正式 OOS 必须另行授权，冻结策略和输入后单次执行。

## 3. 资格与信号

基础池为 `all_a_ex_st_ipo120_ex_bj`，策略资格还检查上市年龄、有效价格、市值、成交额、交易状态和因子覆盖。

当前主规则包括：20 个有效成交额观测、ADV20 不低于 2000 万元、排除基础池流通市值最低 10%、四因子共同有效、共同覆盖至少 70%、有效截面至少 300 只。缺失不填充，资格不足不通过降低门槛制造交易。

C0 固定分数：

```text
价值 = (z_bp + z_sp_ttm) / 2
反转 = -z_rev_20
低波 = -z_vol_20
总分 = (价值 + 反转 + 低波) / 3
```

四个成分必须同时有效，按 `score DESC, ts_code ASC` 确定性排序。候选预算、诊断预算和允许版本由 YAML 与策略注册表共同限制，不能看结果后无限增加试验。

## 4. 信息时间轴

- **T 收盘后**：只用 T 及以前信息形成资格、分数、目标和订单。
- **D 开盘**：D 是 T 后严格下一交易日，只用 D 的实际开盘、限价和交易事实做代理撮合，不能回头重排。
- **D 收盘**：估值、现金和费用更新；收盘风险判断只能影响后续交易日。

标签、IC 和评价收益不能进入信号、组合或订单模块。训练或滚动权重还必须等整截面的实际标签终点早于使用日。

## 5. 目标组合与约束

- 每 20 个交易日调仓，正常目标 100 只，存量排名保留缓冲到 120。
- 股票目标仓位 95%，现金 5%；不加杠杆、不做空。
- 冻结或不可卖持仓继续留账，剩余预算才用于新目标。
- 使用确定性投影靠近等权目标，不做样本内收益拟合。
- 单股目标权重不超过 2%；行业相对偏离上限按当前 YAML 为 10%。
- 市值暴露当前仅作诊断，不作为启用的硬约束。
- 常规单边目标换手不超过 20%；委托和持仓分别受 ADV 限制。
- 不可行、超时或不收敛时不放宽约束，保留仓位、禁止新增风险，只允许预定义风险退出。

数量规则是 R1 研究假设：普通股票按 100 股最小量及递增单位，科创板按当前配置规则，全部可卖持仓的余股退出单独处理；这不等于已验证真实板块交易规则。

## 6. 执行与异常

当前模型为 `daily_open_proxy_v1`：

- 使用 D 日未复权开盘价；买入开盘价不低于涨停价时拒绝，卖出开盘价不高于跌停价时拒绝。
- 停牌、无量、无效价格或状态未知时不假设成交。
- 普通订单当日有效，失败不补选；风险退出每日复查并可重发。
- 买入批次下一交易日才可卖，D 日卖款下一交易日才可用。
- 全天成交额只作事后成交上界，不代表开盘竞价容量。
- 部分成交、拒单和剩余订单必须留痕。

退市或长期无报价资产不能按最后价格虚构卖出。参考账保留最后有效估值，并另报 60/120 个无报价交易日的减值压力；减值不创造现金。

## 7. R1 账户、费用与基准

R1 使用 `adjusted_unit_proxy`：现金按真实模型成交额和费用变化，持仓使用复权研究单位估值，不额外伪造股息或送股。研究单位不等于真实股数，不能还原公司行动现金和股份到账。

主费用假设：双边佣金 3bp、单股票单方向单日最低 5 元，其他成交费代理 0.2bp，卖出税费代理 10bp，并另扣透明冲击成本。压力参数以 YAML 为准。这些是研究假设，不是历史逐日收费表。

主要对照为同资格池被动账户，匹配对照为四因子共同有效子集被动账户。自建指数或统计收益序列只作参考，不冒充官方指数或持有账户。

## 8. 评价与发布

- 使用连续日净值，每份持仓每天只计一次，不能滚乘重叠的 20 日前向收益。
- 报告毛/净收益、回撤、Sharpe、换手、现金、容量、费用、主动收益、跟踪误差、IR 和归因。
- 理想目标、代理成交毛/净账和真实股数账必须分开。
- 所有候选、诊断、失败、空结果和人工查看都登记；负结果不能删除。
- 工程通过与经济晋级分开；无合格策略是合法结论。
- 独立 L3/L4/L5、运行 manifest、预注册、trial 和报告组成证据链。
- 全量与截断、双目录、现金/NAV、PIT、未来扰动和权限检查必须通过。

## 9. 当前边界

R2 所需公司行动、真实单位、整手与结算、公告日历、退市和换码等未验收前保持阻断。正式 OOS 和实盘不因工程通过而自动开放。
